# SM-Agency

A modern digital marketing agency website built with Next.js.

## Features

- Responsive design
- SEO optimized
- Contact form
- Blog section
- Services showcase
- Live projects counter
- AI-powered sales qualification
- Google AdSense ready (ads.txt configured)

## Tech Stack

- Next.js 14
- TypeScript
- Tailwind CSS
- Cloudinary for image optimization

## Installation

1. Clone the repository
2. Install dependencies: `npm install`
3. Run the development server: `npm run dev`
